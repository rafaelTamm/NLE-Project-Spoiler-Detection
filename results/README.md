# Results

This directory contains the exported results used for the final evaluation and analysis.

## Main Classification Results

### `tfidf_results.csv`

Contains the results of the TF-IDF + Logistic Regression baseline for the four experimental settings:

- IMDb → IMDb
- Goodreads → Goodreads
- IMDb → Goodreads
- Goodreads → IMDb

### `modernbert_multiseed_results.csv`

Contains the individual ModernBERT results for all four experimental settings and the three fine-tuning seeds:

- 42
- 123
- 456

This results in 12 experiment rows in total.

### `modernbert_multiseed_summary.csv`

Contains the aggregated ModernBERT results across the three fine-tuning seeds, reported as mean and sample standard deviation.

## Additional Analyses

### `modernbert_confidence.csv`

Contains confidence-based statistics for the detailed ModernBERT prediction analysis.

### `modernbert_length_analysis.csv`

Contains ModernBERT performance statistics grouped by review length.

### `modernbert_cross_domain_error_sample.csv`

Contains the reproducible qualitative cross-domain error sample based on the seed-42 ModernBERT models.

The sample contains 10 false positives and 10 false negatives for each cross-domain direction.

### `goodreads_truncation_analysis.csv`

Contains the derived Goodreads analysis used to investigate whether spoiler evidence occurs beyond the 1,024-token input limit used for ModernBERT.

## Reproduction

The main result files are generated by the notebooks in `notebooks/`.

1. `01_tfidf_baseline.ipynb` generates the TF-IDF baseline results.
2. `02_modernbert.ipynb` generates the multi-seed ModernBERT results.
3. `03_results_analysis.ipynb` combines the results and performs the final analyses.

The exported CSV files are included in the repository so that the final analyses can be inspected without retraining ModernBERT.

The detailed seed-42 confidence, review-length, and qualitative error CSV files were generated during the original Google Colab runs. The corresponding prediction-level analysis workflow is documented in `02_modernbert.ipynb`.

The exported files used for the paper are included in this directory, so the final analysis can be inspected without retraining ModernBERT.
